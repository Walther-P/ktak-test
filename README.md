# KTAK V1.9.1 Integrated

這個更新包已合併：
- 上一輪 V1.9.1 任務地圖／戰術板快速資訊優化
- 本輪任務簡報重排與新增欄位

任務簡報順序：
1. 時間
2. 案情摘要
3. 敵情
4. 執行地點
5. 執行天氣
6. 現場人員
7. 攜帶裝備

新增欄位：
- 任務時間
- 執行地點／目標位置
- 執行天氣／環境狀況

既有欄位保留並重新歸類：
- 案類、案情摘要／現場情況、任務執行方式、補充任務內容
- 敵情風險、嫌疑人數量、嫌疑人背景
- 平民數量、攻堅隊伍組成
- 出動車輛、裝備與數量

更新方法：
- 不需要 Supabase SQL。
- GitHub 覆蓋 index.html、sw.js、manifest.webmanifest。
- 不要覆蓋 config.js。
- 第一次可用 ?v=1.9.1 開啟新版。
