# KTAK Mission Room V1.2

本版沿用 V1.1 的視覺與房間/角色模型，主要修正互動。

## V1.2 修正
- 地圖直線、方形、圓形、自由畫：可直接拖曳移動
- 地圖物件：電腦右鍵、手機點一下開啟操作選單
- 地圖物件可旋轉、縮放、放大、單獨刪除
- 照片與戰術圖樣可由操作選單設定觀察/拍攝扇形
- 快速圖樣改為較專業的 SVG 幾何戰術圖標
- iOS 地圖工具按鈕與側欄提高 z-index，避免被 Leaflet 地圖蓋住
- 戰術板門改為咖啡色長方形
- 戰術板物件：右鍵/點一下開啟旋轉、縮放、刪除選單
- 橡皮擦改為局部擦除筆觸，而非整個刪除物件
- 樓梯分為上樓 / 下樓
- 畫紙下方增加樓層頁籤；樓層名稱可自行輸入

## 安全界線
V1.2 仍是純前端原型，尚未接真正跨裝置後端。
Public GitHub Pages 代表程式碼公開，但 localStorage 中的房間資料不會因此自動公開。
然而本版不應放入真實敏感勤務資料：頁面仍會載入第三方地圖/程式資源，地址搜尋與地圖請求也會送往外部服務；房間密碼目前只是本機原型驗證，並非正式後端身分驗證。

## 部署
與前版相同：把本資料夾內容上傳 GitHub repository 根目錄，Pages 使用 main / root。
