# KTAK Mission Room V1.5

## 本版修正
1. 任務地圖快速圖樣備註
   - 桌機：滑鼠移到快速圖樣即顯示名稱與備註
   - 手機：輕觸圖樣即顯示名稱與備註
   - 不必再進「詳細資訊」才能查看

2. 自訂快速圖樣圖案庫擴充
   - 原有快速圖樣維持不變
   - 自訂圖樣額外增加：觀察、人物、群眾、建築、住宅、倉庫、學校/機關、醫療院所、
     檢查點、道路封鎖、交通錐、旗標、目標、警告、包裹、鑰匙、手機、電腦、天線、
     直升機、船艇、卡車、巴士、犬隻、搜索點、上鎖/管制、一般標記等

3. 戰術板桌機版
   - 修正 V1.4 因手機縮放邏輯造成桌機畫布被縮小
   - 桌機固定 100% 1:1 顯示，不再自動縮小
   - 預設大畫布 2000 × 1400
   - 工作區可水平 / 垂直捲動
   - 左側新增樓層清單，直接切換不同畫布層
   - 可按「＋ 擴大畫布」逐步增加工作區，最高 5000 × 3500
   - 手機 V1.4 雙指縮放保留

## 部署
將本資料夾全部檔案覆蓋原 GitHub Pages repository 根目錄即可。
