# KTAK Mission Room V1.4

本版只針對 V1.3 的兩項需求更新，其餘功能與視覺維持 V1.3。

## V1.4
1. 手機戰術板支援雙指捏合放大 / 縮小
   - 單指仍維持繪圖、選取、移動
   - 雙指 pinch 可在約 75%～500% 間縮放
   - 放大後可在戰術板區域內捲動查看細節

2. 任務地圖新增明確的「自訂快速圖樣」區塊
   - 顯示完整戰術圖案庫，不再藏在下拉選單
   - 點選任一圖案
   - 自行輸入名稱
   - 按「使用此自訂圖樣並放置」
   - 放置後保有 V1.3 的拖曳、長按選取、旋轉縮放、方向扇形與刪除能力

## 部署
解壓縮後，把所有檔案覆蓋 GitHub Pages repository 根目錄即可。
不需要重新設定 GitHub Pages。

## 安全
仍為前端 / 同瀏覽器原型，尚未接跨裝置後端。請勿輸入真實敏感勤務資料。
