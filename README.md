# KTAK Mission Room V1.3

## 本版重點
- 左上角版本改為 V1.3
- 任務地圖地址搜尋回復 V1.1 的台灣門牌拆解與 fallback 邏輯
- 修正 V1.2 地圖物件事件未正確綁定的問題
- 地圖直線 / 方形 / 圓形 / 隨意畫 / 圖樣 / 照片：
  - 切到拖曳模式後可直接拖動
  - 按住 1 秒顯示選取框
  - 右下角 ↻ 把手同時控制旋轉與縮放
  - 再按住 1 秒完成調整、關閉選取框
  - 電腦右鍵 / 手機輕觸：查看、方向扇形、清除方向、刪除
- 方向扇形可套用在所有地圖物件
- 槍械圖示重畫，增加更多專業戰術圖示與自訂命名選擇
- 戰術板使用同一套拖曳 / 長按選取 / ↻ 旋轉縮放手勢
- 戰術板門維持咖啡色長方形，樓梯保留上樓 / 下樓
- 強化 iOS 手機工具列 z-index

## 部署
將本資料夾所有檔案上傳覆蓋 GitHub Pages repository 根目錄即可。
GitHub Pages 設定不需重新建立。

## 注意
V1.3 仍是本機 / 同瀏覽器分頁同步原型，尚未接跨裝置後端。
請勿放入真實敏感勤務資料。
