# KTAK Mission Room V1.1

第一次修正版，依使用者回饋加入：
- 任務簡報：敵情風險、任務執行方式
- 首頁：創建房間 / 加入房間
- 建立者自動為「特勤指揮官・暱稱」
- 房號 + 選填密碼
- 加入者選擇特勤人員 / 偵查隊 / 觀察員
- 第五頁籤：權限管理
- 指揮官可刪除其他人的地圖、戰術板與聊天內容
- 地圖繪圖顏色、工具游標
- 狙擊點、自訂戰術圖樣、車輛/槍械等圖示
- 地圖物件選取、拖曳、旋轉、縮放、單獨刪除
- 快速圖樣與照片：長按約 0.45 秒再拖曳可設定觀察扇形
- 地址搜尋改成台灣地址拆解 + 多組 Nominatim fallback；另保留 Google Maps 精準搜尋 fallback
- 戰術板：俯瞰門、選取/拖曳、旋轉、縮放、單獨刪除、橡皮擦

## 部署
可直接放到 GitHub Pages / Netlify / Cloudflare Pages。

## 重要限制
V1.1 的房間同步仍是 BroadcastChannel + localStorage，只能在同一瀏覽器不同分頁測試真正的房間邏輯。
跨手機 / 電腦同步尚未接後端，因此密碼與角色權限在此版本只是前端原型，不是正式安全機制。
請勿放入真實敏感勤務資料。
